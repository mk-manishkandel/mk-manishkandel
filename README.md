# Hi, I'm Manish Kandel 👋

I build practical software: point-of-sale systems that run real canteens, and tools that make everyday
devices better.

## Projects

### [CafeFlow POS](https://github.com/mk-manishkandel/POS-for-Restaurant)
Point-of-sale and account management for institutional cafeterias with staff and student canteens across
several branches. It has a cashier terminal and admin panel, staff monthly allowances, student pre-orders
by order ID, reports and Excel exports, roles and audit logs, ESC/POS printing, and an integration API.

`React` `TypeScript` `Vite` `Tailwind` `Node.js` `Express` `Socket.IO` `PostgreSQL` `Redis` `PM2`

### [Hack Your TV](https://github.com/mk-manishkandel/Hack-Your-TV)
An Apple TV style launcher and debloat kit for Android TV and Google TV. It removes home screen ads,
replaces Xiaomi PatchWall and makes the TV faster, with no root needed. An AI agent can do the whole
setup from one prompt.

`Java` `Android TV` `ADB` `Shell`
